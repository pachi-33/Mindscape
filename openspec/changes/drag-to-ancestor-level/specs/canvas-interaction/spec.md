## ADDED Requirements

### Requirement: 拖拽插入祖先所在层级

在思维导图与左右逻辑图中，单节点拖拽 SHALL 沿原父节点的祖先链匹配可见兄弟空隙，在命中时显示插入线并按松手位置提交。目标序列包括可见头部节点，命中时提升为头部。

#### Scenario: 跨多级插入

- **GIVEN** 头部下有 A、B、C，X 是 B 的孙子节点或更深的后代
- **WHEN** 用户将 X 拖到 A 和 B 之间，或 A 上方、C 下方
- **THEN** X 成为 A、B、C 的兄弟，按插入线的位置落下，并保留整棵子树

#### Scenario: 拖出有效区域

- **WHEN** 插入线显示后，用户在无有效目标的空白处松开
- **THEN** 清除插入线并保留原有父子关系和顺序
