## ADDED Requirements

### Requirement: 左右逻辑图同级拖拽排序

在左、右逻辑图中，画布 SHALL 允许用户单独拖动一个有父节点的节点，在原父节点下的可见兄弟之间及两端显示插入线，按松手位置移动整棵子树并保留父节点与其他兄弟的相对顺序。

#### Scenario: 插入中间

- **WHEN** 用户将 D 拖至 A 和 B 之间并松手
- **THEN** 画布先显示插入线，松手后 A、B、C、D 变为 A、D、B、C

#### Scenario: 插入首尾

- **WHEN** 用户将 D 拖到 A 上方，或将 A 拖到 D 下方
- **THEN** 对应端点显示插入线，松手后该节点成为首个或末个兄弟

#### Scenario: 在其他父节点的空隙松手

- **WHEN** 节点经过有效插入位置后，在其他父节点下的兄弟空隙或空白画布松手
- **THEN** 取消插入，保留原顺序与父子关系

#### Scenario: 撤销与重做

- **WHEN** 完成一次排序后依次撤销与重做
- **THEN** 分别恢复原顺序和新顺序，子树归属保持一致
