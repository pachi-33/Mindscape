## ADDED Requirements
### Requirement: 子节点提升一级插入
画布 SHALL 在思维导图与左右逻辑图中支持单独拖动子节点到其父节点所在层级的兄弟之间或首尾，显示插入线，并按松手位置提升一级和排序。
#### Scenario: 中间或首尾插入
- **WHEN** 用户把 A 的子节点 X 拖到 A、B 之间，或该序列之前或之后
- **THEN** X 成为 A 的兄弟，按插入线的位置排序，X 的子树跟随
#### Scenario: 撤销提升
- **WHEN** 提升排序后撤销并重做
- **THEN** 一次撤销恢复原父节点与顺序，一次重做恢复提升结果
#### Scenario: 无效松手
- **WHEN** 用户拖出有效区域再松手
- **THEN** 取消插入并保留原树
