## ADDED Requirements
### Requirement: 原子迁移并插入
编辑器 SHALL 一次性完成合法的换父节点和相对位置排序，保留子树，允许单次撤销与重做，拒绝循环引用和无效目标。
#### Scenario: 中间或首尾插入
- **WHEN** 用户把 A 的子节点 X 拖到 A、B 之间，或该序列之前或之后
- **THEN** X 成为 A 的兄弟，按插入线的位置排序，X 的子树跟随
#### Scenario: 撤销提升
- **WHEN** 提升排序后撤销并重做
- **THEN** 一次撤销恢复原父节点与顺序，一次重做恢复提升结果
#### Scenario: 无效松手
- **WHEN** 用户拖出有效区域再松手
- **THEN** 取消插入并保留原树
