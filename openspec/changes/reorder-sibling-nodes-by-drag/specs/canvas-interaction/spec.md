# Spec Delta

## ADDED Requirements

### Requirement: 从同级空隙插入节点

在思维导图布局中，用户单独拖动有父节点的节点时，画布 SHALL 在原父节点下的有效同级空隙显示插入线。用户松手后，系统 SHALL 按该位置调整节点顺序，保留原父节点、子树以及其他兄弟的相对顺序。

#### Scenario: 插入两个兄弟节点之间

- **GIVEN** 同一父节点下的可见兄弟从上到下排列为 A、B、C、D
- **WHEN** 用户将 D 拖到 A 和 B 之间的空白处并松手
- **THEN** 悬停时在 A 和 B 之间显示插入线，松手后顺序为 A、D、B、C

#### Scenario: 插到第一个兄弟节点之前

- **GIVEN** 同一父节点下的可见兄弟从上到下排列为 A、B、C、D
- **WHEN** 用户将 D 拖到 A 上方的有效末端区域并松手
- **THEN** 悬停时在 A 上方显示插入线，松手后顺序为 D、A、B、C

#### Scenario: 插到最后一个兄弟节点之后

- **GIVEN** 同一父节点下的可见兄弟从上到下排列为 A、B、C、D
- **WHEN** 用户将 A 拖到 D 下方的有效末端区域并松手
- **THEN** 悬停时在 D 下方显示插入线，松手后顺序为 B、C、D、A

#### Scenario: 悬停在不同父节点的兄弟之间

- **WHEN** 用户将节点拖到不同父节点下的两个兄弟之间的空白处，或该序列的首尾插入区域并松手
- **THEN** 该区域不显示插入线，节点顺序和父子关系均保持原样

#### Scenario: 撤销与重做同级排序

- **WHEN** 用户通过空隙插入改变同级顺序，再依次执行撤销和重做
- **THEN** 一次撤销恢复原顺序，一次重做恢复调整后的顺序

#### Scenario: 离开有效落点

- **GIVEN** 画布已显示同级插入线
- **WHEN** 用户移到没有有效插入位置或其他有效拖放目标的空白处并松开
- **THEN** 插入提示消失，原顺序和父子关系保持原样
