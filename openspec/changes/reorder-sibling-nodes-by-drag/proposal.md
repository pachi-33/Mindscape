# Proposal

## Why

思维导图布局已有按目标节点及其附近位置换序的手势。用户在同一父节点下调整顺序时，需要能直接选择两个兄弟节点之间的空隙，或整列兄弟节点的首尾位置。

## What Changes

- 在思维导图布局中，单独拖动非头部节点到原父节点下的两个可见兄弟之间，或可见兄弟序列的首端、尾端。
- 悬停时显示插入线。松手后，被拖节点及其子树按该位置重新排列，父子关系保留。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `canvas-interaction`：新增思维导图布局的同级空隙插入与悬停反馈。

## Impact

- 画布识别插入区域，编辑器继续负责排序、保存和撤销。新增手势限于思维导图布局中的单节点排序。
- 实施时按本提案修正此前未提交的实现和说明，把其他布局、头部节点及多选拖动手势恢复到项目基线。
