# Design

## Context

当前主分支的思维导图拖动以节点框及其磁吸范围判定目标，用指针相对目标的位置换序。画布已有拖动反馈，编辑器能按指定兄弟节点的前后调整同级顺序，并保存撤销记录。

## Goals / Non-Goals

**Goals**

- 直接命中同级节点之间和列表两端的空白区域，让插入线和最终提交对应同一位置。
- 通过现有排序入口保留父子关系与撤销记录。

**Non-Goals**

- 跨父节点插入、头部节点空隙排序、批量排序和其他布局的手势调整。

## Decisions

- 根据当前可见兄弟节点框计算插入区域。相邻节点间使用同列的纵向空白，首尾在其外沿设置有限的可命中区域。排除被拖节点作为定位目标。思维导图的左右分支各在可见列内找落点。
- 节点本体命中优先采用现有手势。指针在空白处时，先判断是否位于明确的插入区域，再使用已有磁吸规则。属于其他父节点的插入区域不触发磁吸迁移，避免把拖入空隙误判为拖到节点上。
- 插入线与松手使用同一落点计算，读取当前视觉帧，并将结果转换成“某个兄弟之前或之后”。编辑器继续负责排序、撤销和保存。一级分支的左右侧处理沿用现有布局模式。

## Risks / Trade-offs

- 缩放会影响首尾插入区域的易用性，边缘容差使用屏幕距离计算。测试落点选在节点矩形外，覆盖空隙而非节点半区。
- 前一版本的本地实现改动了其他自动布局。实施时对照主分支，只替换与旧方案有关的代码、测试和说明，保留现有节点本体、换侧和自由布局手势。
