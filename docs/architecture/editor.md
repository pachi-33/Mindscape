# 导图模型与编辑器：现状设计

本文描述当前导图模型及编辑器，外部行为见 [导图模型与编辑规格](../../openspec/specs/mind-map-editing/spec.md)。结论依据源码与现有测试代码，未将推测中的设计动机视为事实；本次整理未运行 XCTest。

## 职责与关键对象

- [MindMap](../../Mindscape/Models/MindMap.swift) 是 `Codable` 值类型，保存 ID、标题、节点数组、布局、主题和时间，提供节点、根节点、子树及广度优先查询。
- [MindNode](../../Mindscape/Models/MindNode.swift) 保存节点 ID、父 ID、文字、备注、图标、折叠、同级顺序、分支方向、颜色和自由布局位置。
- [MapEditor](../../Mindscape/Editor/MapEditor.swift) 是 `@MainActor`、`@Observable` 的当前文档编辑状态中心，负责结构操作、选区、撤销重做、自动保存和历史快照。
- [NodeClipboard](../../Mindscape/Editor/NodeClipboard.swift) 使用系统剪贴板的自定义类型与纯文本，并维护基于剪贴板变化次数的内存缓存。
- [WorkspaceView](../../Mindscape/Views/WorkspaceView.swift) 将编辑器传给 SwiftUI 面板，并通过 `NSViewRepresentable` 连接画布；布局计算与绘制分别由 [LayoutEngine](../../Mindscape/Canvas/LayoutEngine.swift) 和 [MapRenderer](../../Mindscape/Canvas/MapRenderer.swift) 提供。

## 数据结构与编辑流

节点保存在扁平数组中，以 `parentID` 表示父子关系，`order` 表示同级顺序。无父节点或父节点缺失的节点被识别为头部节点；允许多个头部，主头部通常是顺序最靠前的头部。遍历和子树查询包含访问保护，布局层也会防御部分损坏数据。

在当前界面中，节点操作经由 `MapEditor` 修改内存中的 `MindMap`。普通的 `mutate` 会在修改前保存撤销快照、清空重做栈，修改后更新时间、递增 `revision` 并调度保存。选区、专注节点及画布居中/缩放请求也由编辑器携带，画布读取相应状态。保存流程见 [存储现状设计](storage.md)。

## 关键行为与边界

- 新建子节点会展开父节点、选择新节点；头部节点的新增同级操作创建新头部。删除分支会删除其子树，编辑器保留至少一个已有头部节点。
- 移动前检查目标存在、避免自指或移动到后代；只有一个头部节点时禁止将其移成子节点。批量操作先选取顶层节点，避免父子同时选中时重复处理同一子树。
- 同级排序改写同一父节点下的 `order`。思维导图“记住布局”模式还记录一级分支的 `branchSide`；“平衡布局”清除这些记录并由布局计算分配方向。
- 标题跟随由当前标题和主头部文字是否匹配等条件推断，而非单独的持久化开关。设置一个非空、不同于头部及默认占位的标题后，后续修改主头部会保留该标题；若标题再次满足跟随条件，代码会重新将其视为跟随。跟随时标题使用去除前后空白的头部文字，空白文字回退为“新主题”。
- 撤销和重做保存完整 `MindMap` 值快照，每个栈最多 150 步，同时以 40000 个节点为预算并至少保留一个快照。相同节点的连续文本或备注编辑在一秒内可合并。`setTitle` 直接更新状态并调度保存，不经过普通的撤销快照入口；外观同步也显式设为不可撤销。
- 折叠包含选中后代的分支时，选区移到折叠节点。搜索匹配节点文字、备注、图标符号和名称，返回广度优先顺序。

## 剪贴板与兼容性

复制使用自定义 `com.youyanping.mindscape.nodes` 类型，同时写入按层级缩进的纯文本大纲。粘贴自定义节点时重新分配 ID，并按映射恢复子树父子关系；自由位置有偏移。没有有效节点数据时，编辑器尝试将纯文本按缩进和列表前缀转成节点。剪贴板被其他应用修改后，旧缓存不会继续当作当前内容。

`MindNode` 解码时兼容旧的 `emoji` 字段，若缺失部分字段则使用代码中的默认值；`MindMap` 的旧数据若没有 `mindMapLayoutMode`，按“记住布局”解释。更完整的版本迁移和损坏数据行为需要结合具体输入测试，不能据此假定任意旧 JSON 均可解码。

## 测试与待核验项

[MindscapeCoreTests.swift](../../MindscapeTests/MindscapeCoreTests.swift) 含新增编辑及撤销重做、移动排序、最后头部保护、标题跟随、折叠选区、复制粘贴、纯文本大纲和旧布局字段解码测试。该文件还包含自由布局、多选和思维导图拖动相关测试；这些是代码中的测试覆盖线索，本次没有执行测试。

跨入口写入值得补充集成验证：Agent 服务读取数据库并写回后，`AppModel` 为当前文档重新创建编辑器，而界面修改可能仍处于自动保存等待期。需要分别覆盖未保存界面内容与 Agent 写入的组合，不能只根据单一模块测试推断数据不会冲突。

JSON 导入目前主要检查是否能解码且包含节点，并未完整校验父子关系。对带环或父节点缺失的损坏数据，节点删除和最后头部保护等行为需要单独测试；常规编辑规格以有效、无环的父子结构为前提。
